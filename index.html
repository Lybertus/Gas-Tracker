💡 Wie funktioniert diese Prognose?
In 30974 Wennigsen (Deister) fallen ca. 60% des jährlichen Heizbedarfs in den Monaten November bis Februar an, während in den Sommermonaten Juni bis August nur der Warmwasser-Sockel (~1,5% pro Monat) verbraucht wird. Sobald du Ablesungen erfasst, errechnet die App deine individuelle Haushalts-Heizintensität und skaliert die verbleibenden Monate exakt nach dem lokalen Temperaturverlauf.

iPhone 15 Pro Max & GitHub

1
Auf GitHub hochladen:

Erstelle ein neues Repository auf GitHub (z.B. gas-tracker) und lade diese Dateien hoch.

2
GitHub Pages aktivieren:

Gehe im Repository auf Settings → Pages. Wähle bei Source Deploy from a branch, Branch main und Ordner / (root), dann klicke auf Save.

3
Auf dem iPhone öffnen:

Öffne die GitHub Pages URL in Safari auf deinem iPhone 15 Pro Max:
https://<dein-benutzername>.github.io/gas-tracker/

4
Als App installieren:

Tippe in Safari unten auf das Teilen-Symbol (Quadrat mit Pfeil nach oben) → scrolle nach unten und wähle "Zum Home-Bildschirm".

💡 Die App funktioniert danach komplett wie eine native iPhone-App im Vollbildmodus und läuft dank Service Worker auch ohne Internetverbindung im Heizungskeller!
